## Description Writing Guidelines Used

Each description follows these principles:
- **Concise**: 1-2 sentences maximum
- **Informative**: Explains the core strategy or purpose
- **Beginner-friendly**: Uses clear language while maintaining accuracy
- **Context-aware**: Mentions when to use the combo (e.g., "going second", "when disrupted")
- **Highlights key cards**: Names important cards involved in the combo
- **Sets expectations**: Describes what the combo achieves (endboard, disruption, OTK, etc.)
