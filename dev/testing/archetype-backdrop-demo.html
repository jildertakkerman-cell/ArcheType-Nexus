Archetype Backdrop — Design Prototype

This is a standalone demo, not a live page. It pulls real cropped card art for the Blackwing archetype straight from the ygoprodeck API (images.ygoprodeck.com/images/cards_cropped/{id}.jpg) and shows three ways to use it as background texture. Use the panel in the bottom-right to tune opacity/blur live — those are the exact values a shared CSS component would expose as variables.

Pattern 1 — Hero Banner Collage above the fold

Two pieces of art anchored to the left/right edges, blurred and desaturated, under a gradient scrim that fades to solid background toward the bottom. Only the title sits on top, so a higher opacity (~20%) still reads as clean.

Pattern 2 — Section Watermark mid-page

One large art piece bleeds in from the edge of a themed section (e.g. a boss-monster showcase), mask-faded so it dissolves into the background rather than ending on a hard edge. Kept very low opacity (~8-10%) since body copy sits directly over part of it.

Pattern 3 — Ambient Page Background whole page

Two glows anchored in opposite corners, fixed behind the entire page — you're seeing them right now, top-left and bottom-right of this demo. Each is its own radial-masked element so they feather into the background instead of ending on a hard edge. It's the same art as the collage/watermark above but reused rather than re-fetched, so it costs no extra requests.

Implementation notes

• Contrast is enforced by a scrim independent of the art's opacity slider — even at 100% opacity the text stays readable, because the gradient/radial overlay is a separate layer.
• filter: blur() grayscale() is applied to the art, never to text.
• Reuses card IDs already fetched by CardLoader for the page's combo-step images — no extra API calls needed beyond swapping the URL path from cards to cards_cropped.
• On prefers-reduced-motion or low-end devices, skip the ambient layer's blur (it's the most expensive paint) and keep only the banner.
